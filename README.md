## `> ls featured-projects/`

<details open>
<summary><b>&#9654; Haivon &mdash; AI-Powered Career Guidance Platform</b></summary>
<br>

Final Year Project: a 10-module AI career guidance platform combining a fine-tuned LLM, OCR-based transcript parsing, and a recommendation engine.

| Aspect | Detail |
| :-- | :-- |
| **Stack** | FastAPI &middot; PostgreSQL &middot; React &middot; Qwen2.5-7B (QLoRA) &middot; EasyOCR &middot; XGBoost |
| **Scale** | 10-module platform covering assessment, recommendation, and opportunity discovery |
| **Impact** | BERTScore 0.84 &middot; 70% field-recommendation accuracy &middot; Perplexity 7.89 |
| **Status** | Private (university FYP) |

Fine-tuned the LLM via QLoRA, re-engineered training labels to fix near-random model accuracy, redesigned the user flow around an interest-first domain-filtered quiz, and built a Playwright-based scraper for live opportunity data. Presented to an external examiner with full Q&A on model internals and architecture decisions.

</details>

<details>
<summary><b>&#9654; Algorithmic Trading Bot & MT5 Expert Advisor</b></summary>
<br>

A production-ready multi-file trading system for forex pairs, XAUUSD, BTCUSD, and indices, paired with a live MT5 Expert Advisor.

| Aspect | Detail |
| :-- | :-- |
| **Stack** | Python &middot; MetaTrader 5 &middot; LSTM &middot; PPO (RL) &middot; Flask |
| **Scale** | Multi-instrument system spanning forex, gold, BTC, and indices |
| **Impact** | Risk firewall + daily loss limits; ATR-based dynamic SL/TP with EMA trend filtering |
| **Status** | Private (client work) |

Combines indicator-based, LSTM, and PPO reinforcement-learning signal modules behind a risk firewall and MT5 executor, with a Flask dashboard for monitoring. The EA layer adds ATR-based dynamic stop-loss/take-profit, EMA trend filters, trailing stops, and daily loss limits.

</details>
